## [0.1.0] — 2026-08-17

### Added

- Qt/QML dashboard with 5 pages: cluster, pulse, explore, alerts, and drill-down views
- Prometheus integration: node/container metrics, sparkline history
- Alertmanager integration: critical alert screen pre-emption
- k3s API client: namespace/pod listing, pod logs, events
- Touch navigation: view stack, auto-rotation, idle reset
- Log stream with bounded ring buffer, follow/pause/resume
- RBAC deployment, systemd unit, install script
- 74 pytest tests covering data layer, navigation, log streaming, sorting
